# 星露谷风格婚礼请柬 · 使用说明

这是一份像素风（星露谷物语风格）的电子婚礼请柬，**全部信息都在 `config.js` 一个文件里修改**，改完保存、刷新页面即可看到全部更新（倒计时、婚礼日历、书简、地点页、美食页、闲游页会自动联动）。

## 一、怎么编辑

用记事本 / 文本编辑器（推荐 VS Code）打开 **`config.js`**，按文件里的中文注释逐项修改即可：

| 想改的内容 | 在 config.js 中修改的位置 |
|---|---|
| 新郎 / 新娘名字、首页称呼 | `groom` / `bride` / `coupleName` |
| 婚礼日期、时间、农历 | `date` 下的 `year` / `month` / `day` / `time` / `lunar` |
| 城市、地点名称、坐标 | `location` 下的 `city` / `name` / `copyAddress` / `coordinates` |
| 地图导航链接 | `location.mapUrl`（在高德/百度地图点"分享"复制链接） |
| 地图截图 | 用你们城市的地图截图覆盖 `map.png` 文件 |
| 高铁站名 | `location.highSpeedRailStation` |
| 邀请信文案 | `letter` 整段都可以自由改写 |
| 美食 / 闲游内容 | `food.list` / `tour.list`（图片对应替换 `lcyrt.jpg`、`njnrm.jpg`、`gyh.jpg`、`pf1.jpg`、`pf2.jpg`） |

修改后**保存文件 → 刷新页面**即可。若改了婚礼日期，日历会自动重新生成对应月份，倒计时也会自动重算。

## 二、怎么预览

- 直接双击打开 `index.html` 即可在浏览器中预览（建议使用 Chrome / Edge）。
- 首页需要先**点击爱心按钮**才会解锁翻页并播放背景音乐（浏览器自动播放限制，属正常现象）。

## 三、怎么发给朋友（部署上线）

有几种方式，任选其一：

1. **微信分享**：把整个文件夹压缩成 zip 发给朋友解压后打开 `index.html`（推荐小白使用）。
2. **GitHub Pages 免费托管**（推荐）：把本文件夹上传到你自己的 GitHub 仓库，在仓库 Settings → Pages 中开启，即可获得一个永久链接，直接转发给所有人。
3. **Gitee Pages / 云服务器**：国内访问更稳，按对应平台教程部署即可（域名需备案，可先用 IP 加端口方式）。

## 四、微信 / 朋友圈 / PC 适配说明（已做好）

### 1️⃣ 发微信好友 / 群
- 部署获得链接后，直接把链接发到微信聊天里即可（手机微信内直接打开，页面已做手机适配）。
- 部署后把 `index.html` 里的 `og:image` 改成完整地址（`https://你的域名/og-image.png`），好友在聊天里点开链接时，微信会自动显示漂亮的**横版分享卡片**（预览图见 `og-image.png`，1200×630）。

### 2️⃣ 发微信朋友圈
- 朋友圈不能放链接，直接发图片即可：使用项目里的 **`wechat-card.png`**（1080×1350 竖版像素风请柬卡片，含新人名、时间、地点），配一句文案，例如：
  > 💌 我们要结婚啦！2026年11月20日，六安市金安区吉事文华南山店（华野大厦）梦幻花海厅，期待你的到来～完整电子请柬见评论区/私聊链接 🥂
- 如果想把卡片换成你们自己的照片：把 `wechat-card.png` 里的 `bg.png` 换成你们的婚纱照（保持正方形裁切效果最佳），再用浏览器打开 `share-card.html` 截图（或用任意图片工具导出）即可。

### 3️⃣ PC 端查看
- 页面已适配 PC：电脑浏览器打开链接后，请柬会在屏幕中央以手机竖版呈现，两侧是深色像素网格背景，观感协调，鼠标滚动翻页、点击右上角圆点可跳转页面。

## 五、文件结构

```
wedding-invitation-editable/
├── index.html      # 页面骨架（一般无需修改）
├── config.js       # ✏️ 婚礼信息配置（改这里！）
├── script.js       # 逻辑脚本（一般无需修改）
├── styles.css      # 样式（一般无需修改）
├── bg.png          # 首页背景图
├── sprite.png      # 像素小动物精灵图
├── car.png         # 自驾图标素材
├── map.png         # ✏️ 地图截图（已定位到吉事文华南山店·华野大厦，可自行替换）
├── bgm.mp3         # 背景音乐（可替换成你们喜欢的音乐）
├── wechat-card.png # ✏️ 朋友圈分享卡片（1080×1350 竖版，可直接发朋友圈）
├── og-image.png    # ✏️ 微信链接分享卡片（1200×630 横版，部署后用于 og:image）
├── share-card.html # 朋友圈卡片的源文件（改背景/文字后，用浏览器打开截图即可重新导出）
├── share-card-og.html # 横版卡片的源文件
├── lcyrt.jpg       # 美食图：三十铺板鸭（可替换）
├── njnrm.jpg       # 美食图：皖西吊锅（可替换）
├── gyh.jpg         # 闲游图：皖西大裂谷（可替换）
├── pf1.jpg         # 闲游图：大别山石窟（可替换）
├── pf2.jpg         # 闲游图：悠然南山度假区（可替换）
└── fusion-pixel-12px-proportional-zh-hans.woff2  # 像素字体
```

> 小提示：背景音乐替换成同名文件 `bgm.mp3` 即可；想换首页背景直接把 `bg.png` 覆盖成新图（建议保持像素风格与相近比例）。地图截图与美食/闲游插画均为 AI 生成或程序合成，可直接替换为你自己的实拍图。
